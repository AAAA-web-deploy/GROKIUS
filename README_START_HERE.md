# Grokius ETH Static Website

This is a plain HTML/CSS/JS website. No Node.js, npm, or build step is required.

## Quick deploy with GitHub Pages
1. Extract this ZIP.
2. Open `config.js` and replace the placeholder token info:
   - `tokenName`
   - `ticker`
   - `contractAddress`
   - `xUrl`
   - `telegramUrl`
   - `buyUrl`
   - `chartUrl`
   - `explorerUrl`
3. Upload all files to a GitHub repository.
4. In GitHub, go to **Settings → Pages**.
5. Set **Deploy from a branch**.
6. Choose **main** and **/(root)**.
7. Save.
